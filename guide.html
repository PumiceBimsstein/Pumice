01 / CONCEPT

基本の3層構造

Pumiceは、文書を「本棚」「本」「ページ」の3つの階層で整理します。

PAGE

ページ

Markdown文書そのもの。

BOOK

本

ページをまとめたもの。特定のテーマやプロジェクトをまとめて1冊の本とします。

SHELF / CATEGORY

本棚

本をまとめたもの。「数学」「物理」「日記」などのテーマごとに本棚を作ります。

安心の完全ローカル設計

外部サーバーとの通信やAIによるテキスト送信は一切行われません。書いた内容はすべてお使いのブラウザ内部に自動で保存されます。

02 / NAVIGATION

画面と移動方法

Pumiceには目的に応じた3つの主要な画面があります。

LIBRARY

本棚一覧画面

すべての本棚が内容の一部とともに並びます。

BOOKS

本一覧画面

選択した本棚の内容です。その本棚に収められている本が並びます。

PAGE VIEW

ドキュメント画面

本を開き、ページを閲覧・編集するための画面です。

画面を行き来する

各ページの上部から本の一覧へ、また本の一覧から本棚の一覧へと、階層を上がることができます。 また、フッターのボタンから本の一覧と本棚の一覧へ移動できます。

03 / MODES

3つの閲覧・編集モード

ドキュメント画面（PageView）には、右上の切り替えボタンから選べる3つのモードが用意されています。

VIEW MODE

VIEW（閲覧）

整形されたMarkdownを読むための標準モードです。

EDIT MODE

EDIT（編集）

文章を直接編集するモードです。入力内容は自動的に保存されます。

PAGES MODE

PAGES（構成管理）

マウスのドラッグでページの並べ替えや、ページの複製と削除が行えます。

閲覧と編集のスクロール同期

VIEWモードとEDITモードを切り替えても、読んでいたスクロール位置が保たれるため、長文でも迷わず続きを編集できます。

04 / PAGES

ページ送りと追加・削除

本をめくるようにページを切り替えることができます。

ページをめくる

  • 画面下のシークバー: クリックして特定の位置にジャンプできるほか、シークバーの上でマウスホイールを回転させるだけで前後のページへ素早く送れます。
  • キーボード矢印キー: VIEWモード時、キーボードの ←（前のページ）/ →（次のページ）でページをめくることができます。
  • 右サイドバーのアイコン: 下部の左右矢印アイコンをクリック、またはその周辺でマウスホイールを回転させます。

ページの追加・複製・削除

  • 追加: 右サイドバーの「+ Next Page」を押すと、現在読んでいるページの直後に新しい白紙ページが挿入されます。
  • 複製: 「PAGES」モードに切り替え、複製したいカードの「copy」ボタンを押すと内容を丸ごと複製できます。
  • 削除: EDITモード中のフッターにある「Delete This Page」、またはPAGESモードのカード右上にある「×」ボタンから削除できます。
05 / ORGANIZE

本棚と本の整理

タイトルを変更する

本棚の名前や本のタイトルは、カードの文字部分やページ上部でタイトル部分をダブルクリックすると入力ウィンドウが開き、いつでも名前を変更できます。

ドラッグ＆ドロップで並べ替える

一覧画面に並んでいる本棚カードや本カードは、マウスでドラッグして好きな順序に並べ替えることができます。PAGESモードでのページ順の入れ替えも同様に行えます。

目次プレビュー

一覧画面で各本棚にマウスカーソルを乗せると「本棚に含まれる本の一覧」が、本に乗せると「本の中の見出し（H1）一覧」がポップアップ表示されます。項目をクリックすれば、その本やページへ直接ジャンプできます。

06 / SIDEBAR & SEARCH

目次と全文検索

画面左側のサイドバーは、ドキュメントの探索・ナビゲーションに特化しています。

サイドバーの3つのタブ

  • Library: すべての本棚を一覧表示。
  • Books: 選択している本棚の中の本を表示。
  • Contents（目次）: 開いている本全体の目次を表示します。見出しをクリックすると該当するページと場所へ瞬時にスクロールします。上部の「HEADING LEVEL」セレクターで表示する見出しレベル（H1〜H3）を絞り込めます。

全文検索

左サイドバー上部の検索ボックスに文字を入力すると、本棚全体を横断して検索を行います。

通知サイン

選択中ではない本棚や本に検索ヒットがある場合、LibraryタブやBooksタブの上に黄色い丸（●）が点灯してヒットの存在を教えてくれます。本文内でも一致したキーワードがハイライトされます。

07 / WRITING

Markdownと数式記法

Pumiceは標準的なMarkdown構文に対応しています。見出し、リスト、太字、表（テーブル）、引用などを直感的に記述できます。

ページの自動タイトル付け

ページの本文1行目を # 見出し で始めると、その文字列が自動的にページのタイトルとして反映されます。 ページのタイトルはテキストファイル(.txt)やマークダウンファイル(.md)として出力する際のファイル名として使用されます。

コードブロック

バッククォート3つ（```言語名）で囲むと、プログラミング言語の構文が自動でハイライトされます。

数式（LaTeX）の記述

ブロック数式・インライン数式の両方に対応しています。ChatGPTやClaudeなど各種AIが出力する記法にも対応しています。

独立した数式ブロック（中央揃え）:

```math
G_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}
```

08 / CUSTOMIZE

見た目のカスタマイズ

  • THEME： ライトモードとダークモードの切り替え。
  • STYLE： 文書の表示スタイルの切り替え。
  • FONT SIZE： 画面全体の文字サイズを微調整。
  • Width： 本文の幅。フッターから調整可能。

サイドバーの非表示

  • 右側サイドバーの最上部のHide Sidebarをクリックするとサイドバーが非表示になります。
  • 非表示中は、右下のコントローラーのNormalボタンで再表示。
  • コントローラーのLeft Menuボタンで左側サイドバーだけを表示できます。
09 / BACKUP

保存と入出力

データはブラウザのストレージに常時自動保存されますが、バックアップや別端末への移行も簡単に行えます。

全データのバックアップとインポート

  • 画面左下のアイコンをクリックすると、全データのバックアップファイル(.json)がダウンロードされます。
  • バックアップファイルはMenuのImport Backupでインポートできます。
  • MenuのDownload ZIPで全文書をマークダウンとテキストファイルにしてZIPファイルで出力します。

本棚や本のデータ

  • 各一覧画面で本棚や本のEXPORTからJSONかZIPを選択するとダウンロードされます。
  • 一覧画面の上部にあるImportからJSONファイルをインポートできます。
  • ドラッグアンドドロップでもインポートが可能です。
  • 形式が合わないファイルは無視されます。

ページ単位でのインポートとエクスポート

  • 右側サイドバーのEXPORTボタンで表示中のページをエクスポートできます。
  • 同じ場所のImportでページをインポートできます。
  • ドラッグアンドドロップでもインポートが可能です。

バックアップは必須

ブラウザに保存されたデータはディスクの空き容量が少なくなったり、ブラウザのキャッシュクリアで消えてしまう可能性があります。定期的にバックアップを取ることをおすすめします。
